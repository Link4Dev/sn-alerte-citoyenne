# Contribuer au projet

Merci de votre intérêt pour Alerte Citoyenne ! Ce projet est ouvert à toute contribution : correction de bugs, nouvelles fonctionnalités, traductions, amélioration du design.

## Vous voulez juste créer la plateforme de votre quartier ou ASC ?

Ce n'est pas une contribution au code — voyez plutôt [GUIDE-ASC.md](GUIDE-ASC.md), qui explique comment dupliquer le projet pour votre propre zone.

## Vous voulez améliorer le projet d'origine ?

1. Faites un **Fork** du dépôt
2. Créez une branche pour votre modification : `git checkout -b ma-amelioration`
3. Faites vos changements et testez-les localement (ouvrez simplement `index.html` dans un navigateur, avec vos propres clés de test Firebase)
4. Envoyez vos changements : `git commit -m "Description claire du changement"` puis `git push`
5. Ouvrez une **Pull Request** sur le dépôt d'origine en expliquant ce que vous avez changé et pourquoi

## Idées de contributions bienvenues

- Modération des signalements (éviter les faux signalements ou le spam)
- Export des signalements pour les autorités (CSV, tableau de bord)
- Filtres par type d'incident ou par période sur la carte
- Notifications automatiques (e-mail, SMS) en plus de WhatsApp
- Traduction de l'interface en wolof ou dans d'autres langues locales

## Signaler un problème

Si vous rencontrez un bug ou avez une suggestion, ouvrez une **Issue** sur le dépôt GitHub en décrivant le problème le plus précisément possible (ce que vous avez fait, ce qui s'est passé, ce que vous attendiez).
